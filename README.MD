# ระบบสร้างภาพนำเสนอผลการดำเนินงาน

เว็บแอปสำหรับศูนย์พัฒนาราษฎรบนพื้นที่สูงจังหวัดลำปาง ใช้จัดภาพกิจกรรม เพิ่มข้อความและวันที่ แล้วบันทึกเป็นไฟล์ JPG สำหรับประชาสัมพันธ์

**เว็บไซต์:** https://htdc-info.vercel.app

## ความสามารถ

- เลือกรูปแบบภาพได้ 4 แบบ: ภาพเดียว, 2 ภาพ, 3 ภาพ และภาพเดียวพร้อมข้อความทับบนภาพ
- เลือก เปลี่ยน หรือลบภาพในแต่ละช่อง พร้อมซูมและลากเพื่อจัดตำแหน่ง
- กรอกหัวข้อ รายละเอียด วันที่ และข้อความมุมซ้ายล่าง
- ปรับขนาดตัวอักษรคำบรรยายได้ตั้งแต่ 10–50 pt โดยระบบจะลดขนาดอัตโนมัติเมื่อข้อความไม่พอดีพื้นที่
- ดูภาพตัวอย่างขนาดจริงและบันทึกเป็น JPG คุณภาพ 95%
- รองรับการใช้งานบนคอมพิวเตอร์ แท็บเล็ต และสมาร์ตโฟน

| รูปแบบ | จำนวนภาพ | ขนาดไฟล์ภาพ |
| --- | ---: | --- |
| 1 | 1 ภาพ | 1522 × 1272 px |
| 2 | 2 ภาพ | 1522 × 1272 px |
| 3 | 3 ภาพ | 1522 × 1272 px |
| 4 | 1 ภาพ พร้อมข้อความทับบนภาพ | 1920 × 1080 px |

## วิธีใช้งาน

1. เลือกรูปแบบการจัดวางภาพ
2. กด **เลือกรูปภาพ** ในแต่ละช่อง หรือกดบนช่องภาพในพื้นที่ตัวอย่าง
3. ลากภาพเพื่อปรับตำแหน่ง และใช้แถบซูมหรือปุ่มรีเซ็ตตามต้องการ
4. กรอกข้อความและวันที่ แล้วปรับขนาดตัวอักษร
5. ตรวจสอบภาพด้วยปุ่ม **ดูภาพตัวอย่างขนาดจริง**
6. กด **บันทึกไฟล์ JPG** บนมือถือหรือแท็บเล็ต เมนูแชร์ของอุปกรณ์อาจปรากฏให้เลือกบันทึกภาพ

ควรตรวจสอบข้อความและความยินยอมในการเผยแพร่ภาพให้ถูกต้องก่อนบันทึกและนำไปใช้

## การรันบนเครื่อง

โครงการใช้ HTML, CSS และ JavaScript ฝั่งเบราว์เซอร์ ไม่ต้องติดตั้งแพ็กเกจหรือสั่ง build

```bash
git clone https://github.com/omegapiammani-collab/Htdc-Info.git
cd Htdc-Info
python3 -m http.server 8000
```

เปิด `http://localhost:8000` ในเบราว์เซอร์ หากไม่มี Python สามารถใช้ static HTTP server อื่นแทนได้

## โครงสร้างไฟล์

```text
index.html          หน้าจอ สไตล์ และการวาดภาพด้วย Canvas
assets/layout4/     โลโก้และไฟล์ภาพสำหรับรูปแบบที่ 4
README.MD           คำแนะนำโครงการ
```

## การทำงานและข้อควรทราบ

- การจัดภาพและสร้าง JPG ทำงานในเบราว์เซอร์ โดยไฟล์ภาพที่เลือกใช้ผ่าน FileReader และ Canvas
- ควรเก็บ `index.html` และโฟลเดอร์ `assets` ไว้ด้วยกัน เพื่อให้รูปแบบที่ 4 โหลดโลโก้ได้
- หน้าเว็บเรียกใช้ฟอนต์ Prompt และ Sarabun จาก Google Fonts หากโหลดไม่ได้ เบราว์เซอร์จะใช้ฟอนต์สำรอง ซึ่งอาจทำให้หน้าตาข้อความเปลี่ยนไป
- การบันทึกภาพบนอุปกรณ์เคลื่อนที่ขึ้นอยู่กับเบราว์เซอร์และระบบปฏิบัติการ หากมีเมนูแชร์ ให้เลือกตัวเลือกบันทึกภาพของอุปกรณ์
- ข้อความตัวอย่างเป็นเพียงตัวอย่าง ควรแทนด้วยข้อมูลจริงก่อนเผยแพร่
